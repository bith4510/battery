讀取 iPhone／iPad 的「分析資料」檔（Analytics-*.ips.ca.synced），顯示比「設定」更詳細的電池數據，並在本機保存歷史、畫趨勢圖。

- 檔案只在瀏覽器內解析，不上傳任何資料；歷史紀錄存在瀏覽器本機。
- 加入主畫面後可離線使用。

## 使用
1. iPhone：設定 → 隱私權與安全性 → 分析與改進功能 → 開啟「分享 iPhone 分析」（iPad 為「分享 iPad 分析」）。
2. 同一頁的「分析資料」中找 Analytics- 開頭的檔案 → 分享 → 儲存到檔案。
   - 通常每天產生一份；最新那份和 session 小檔常常沒有電池紀錄，這時選前一天的。
3. 開啟本頁 → 選擇檔案（可一次選多份）。用 Safari 分享 → 加入主畫面後可離線使用。
4. 也可用捷徑自動讀入（步驟見 `shortcut/SHORTCUT.md`）。

## 畫面內容
- **裝置與型號**：多台裝置（例如 iPhone 和 iPad）的紀錄自動分開；依「首次使用週」區分，沒有這項資料的檔案用電池特徵歸回同一台。型號依容量自動推測，也可手動選或自訂設計容量。
- **健康度**：系統顯示值、標稱容量、實際可用容量（FCC）、化學容量（Qmax）各種算法並列，並標明哪個是 iOS 用的、哪個適合當衰退依據。
- **循環與使用年資**：循環次數、首次使用（Apple 只記到週，顯示 7 天範圍）、平均每天循環、累計運轉時間。
- **容量明細、溫度、電壓與電流**（含充放電倍率 C-rate）。
- **當天使用時間、充電習慣、內阻表、電池狀態、全部原始欄位**。
- **歷史與比較**：趨勢圖（日期或循環次數為橫軸、回歸與移動平均）、兩個日期比較；匯出 JSON／CSV，匯入可疊加不重複。

## 容量怎麼看
| 名稱 | 意義 | 用途 |
|---|---|---|
| 標稱容量（Nominal） | 電量計長期平滑後的容量 | ★ 衰退程度的依據；iOS 的健康度約等於它 ÷ 設計容量 |
| 實際可用容量（FCC） | 目前充滿後實際能用的電量 | 每天會上下波動，看當下狀態 |
| 化學容量（Qmax） | 電芯化學上的總容量，不含內阻損失 | 偶爾才更新，通常比上面兩個高 |

- 系統顯示的健康度不會每天更新，可能停在舊值一段時間；和「標稱 ÷ 設計」差 1% 屬正常。
- 分析資料檔不含型號與設計容量，健康度百分比依所選型號計算。內建 iPhone 30 款、iPad 29 款（iPadOS 26／27 支援機型）的設計容量；Apple 未正式公布 mAh，數值取自監管資料、拆解標籤與媒體交叉比對，不確定者標「推估」。
- 欄位單位或意義不確定者，畫面上標「推定」或「未知」。
