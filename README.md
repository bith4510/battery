# 電池健康度 Plus（網頁版）

讀取 iPhone「分析資料」檔（Analytics-*.ips.ca.synced），顯示比「設定」更詳細的電池數據：
多種健康度計算、容量明細、循環與使用天數、溫度、電壓電流、當天使用時間、充電習慣、內阻表、全部原始欄位，
並在本機保存歷史紀錄畫趨勢圖、比較兩個日期。

- 檔案只在瀏覽器內解析，不上傳任何資料。
- 分析資料檔不含型號與設計容量，健康度百分比依使用者選的型號計算；內建 iPhone 13～18 Pro Max、SE 3、Air、Duo 共 30 款設計容量，取自監管資料、拆解標籤與媒體交叉比對，Apple 未正式公布 mAh。
- 欄位單位或意義不確定者，畫面上標「推定」或「未知」。
- 非 Apple 官方工具。

## 使用
1. 設定 → 隱私權與安全性 → 分析與改進功能 → 開啟「分享 iPhone 分析」。
2. 「分析資料」中找最新的 Analytics- 檔 → 分享 → 儲存到檔案。
3. 開啟本頁 → 選擇檔案。用 Safari 分享 → 加入主畫面後可離線使用。

## v1.2 新增
- 捷徑整合：分析資料檔 → 分享 → 捷徑 → 自動開本頁分析並記錄（步驟見 `shortcut/SHORTCUT.md`）。
- 歷史趨勢：橫軸依實際日期或循環次數；最小平方法回歸（附 R²）與移動平均；資料少於 5 筆或跨度不到 30 天時不顯示衰退率。
- 比較表加「與第一筆比」。
- 匯出 JSON（完整、可再匯入堆疊）與 CSV（Excel，UTF-8 含 BOM）；匯入可多選 JSON、分析資料檔、捷徑精簡檔，同一份不重複。
- 充放電倍率（C-rate＝電流 A ÷ 設計容量 Ah）、Apple 官方循環定義與各代 80% 容量循環目標（只列官方有公布的型號）。
